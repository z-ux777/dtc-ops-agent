Case study: DTC Ops Agent

An AI operations layer for a Shopify + Klaviyo style brand, wired into n8n. Built by Zvi Adler. Runs on mock data, no paid APIs.

The problem

A DTC brand with a small team loses hours every week to the same work: pulling a KPI scorecard, figuring out why a launch is soft, building reorder lists, and answering "where is my order" in two languages. I run a DTC supplement brand where this is weekly work. This project packages it as a clean, testable system on mock data.

How it is built

  • Python standard library only; clone and run in a minute
  • Small HTTP API (/webhook/support, /report/weekly, /launch/check, /segments/replenishment)
  • Three importable n8n workflows: support webhook, Monday scorecard alert, daily Klaviyo replenishment
  • Optional OpenRouter LLM for wording, with a safe offline fallback
  • 14 automated tests, including the API and n8n workflow wiring

Guardrails

  • Every send, refund and Klaviyo push goes to an approval queue first
  • No medical advice; health questions always go to a person
  • Consent flags respected before any marketing event
  • Rules decide routing; the model only polishes wording
  • Keys are placeholders; live nodes ship disabled

How I would roll it out at a real brand

  • Week 1: connect Shopify and Klaviyo read access, run in shadow mode, compare drafts against what the team actually sent.
  • Week 2-3: turn on auto-send only for intents with a clean record (order status), keep humans on money and health topics.
  • Week 4: scorecard and launch alerts in Slack; measure hours saved and first-response time against the baseline.
